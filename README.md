# Pokemon Trainer Hub

Welcome to the place to be if you are a pokemon trainer!
In this app you will be able to browse the first generation of pokemon(1 - 151)\* and select the ones that are your favorites.

If you want to actually become a pokemon trainer, create a profile! This is where the fun begins.

With a profile, you can:

- Save your favorites, and keep track of them every time you log in
- Create teams of pokemon that are your very own. I see you with 6 Charizards!
- If you have a team that you really like, favorite it.
- Accidentally add a pokemon you didn't want to, or the name isn't working, edit that team!

When browsing the pokemon, feel free to use the type filter system.
Choose from any of the 18 types to see pokemon that have those types.
You may be surprised at a Pokemon's secondary type. Did you know Jynx was Ice?

If you want to get down to the nitty gritty and check out a full pokemon profile, check out the info page.

Simply hover over any pokemon in the Pokedex or Team builder and click on the info "i" button.
You will be taken to the hub for all information that pokemon.

Once on their profile page, you can get a beeter look at a Pokemon's sprites, flavor text entries, and even hear their battle cry!
Want more info? Go through the tabs section and you will see how that Pokemon's strengths, weaknesses, and immunities(if any).
You can also see the base stats, the evolution chain, and the move set for that pokemon.

Features to come:

- Saving user and teams info to a database
- Simulated battle system
- Pokemon catching mechanic(gotta catch 'em all!)
- Travel to different areas and encountering pokemon form that area
- Filtering the pokedex by "all", "seen", and "caught"
- EXP and level up system
- Support for all generations of pokemon(starting with gen 2 and onward)
- Even more!

Stack used:

- React - UI code library
- PokeApi - 3rd party open access Pokemon API

Techniques Used:

- Custom Hooks
- Function React Components
- DRY(as much as I could find)
- Javascript Recursive Functions
- Javascrip Classes
